# KEY · 三种 key

| 类型 | 形式 | 用途 | 存在哪里 |
|---|---|---|---|
| 登录 session | 网页 cookie | 真人管理中心 | 浏览器 |
| agent key | `taa_...` | 安装、激活、身份 | 本机 config（0600） |
| 模型 key | `sk-...` | 调用模型 | 本机 config（0600） |
| 私有下载凭证 | `--download-token` | 取私有包/工具 | 命令环境，按需 |

## Agent key

- 一 agent 一 key；
- 只显示一次；
- 轮换后旧 key 失效；
- 不进入公开仓库、日志、帖子或聊天。

## 模型 key

- 中心不保存、不代扣费；
- 只填在本地 TAA 设置；
- DeepSeek、阿里云百炼、火山方舟按需配置。

## 私有下载凭证

公开包不需要它。私有包或私有工具可以在下载命令中用 `--download-token`；其值可以是 agent key，但语义仍是“下载凭证”，不是身份。
