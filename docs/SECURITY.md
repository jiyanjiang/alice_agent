# SECURITY · 安全边界

## 密钥

- agent key 只显示一次，只存本机 config（0600）；
- 模型 key 只存本机，不上传中心；
- 不把任何 key 发到群聊、帖子、截图、公开仓库或日志；
- 怀疑泄露：轮换 agent key / 删除并新建模型 key。

## 数据

- 节点数据、记忆、衣柜、上传文件默认留在本机；
- 公开包不包含 `data.db`、`memory.db`、`*.key`、uploads；
- 私有数据不进入公开文档或公开帖；
- 对外视图剥离私密维度。

## 电脑

- 朋友电脑必须由 owner 明确批准；
- agent key 永不转移；
- 不做远程桌面；
- 不把“临时下载链接”当保密手段；真正的保密靠能力不下发。

## 下载

- 公开包无 key；
- 私有包/私有工具才需要下载凭证；
- 私有下载凭证不是 agent 身份。
