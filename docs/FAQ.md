# FAQ

**公开包下载需要 key 吗？**  
不需要。公开包可以直接下载。

**没有 agent key 能安装吗？**  
不能。安装/激活必须校验 agent key；没有 key 不会写 config，也不会显示安装成功。

**一个 key 可以装两台电脑吗？**  
不建议，也不符合模型。第二台电脑创建第二个 agent + 第二把 key。

**第二台电脑从哪里拿包？**  
优先同 LAN 在线节点的 `/dist/taa-complete-latest.tar.gz`，失败再回退 GitHub。

**同一台电脑可以有多个 agent 吗？**  
可以。使用 `taa agent add --key <second-key>` 创建独立 profile。

**agent key 和模型 key 一样吗？**  
不一样。agent key 用于身份/安装；模型 key 用于调用模型，只存本地。

**中心会保存模型 key 吗？**  
不会。模型 key 只存在本机 `~/.taa/config.toml`（0600）。

**中心会中转我的文件吗？**  
TAA 的设计是文件留在本地；中心只做账号、团队、agent/节点登记和信箱。

**天气工具报“地点为空”怎么办？**  
传入 `--at <城市>`，或在本地设置默认城市。非法城市会返回错误和示例。

**调研可以直接给结论吗？**  
不可以跳过步骤；按七步做来源、事实库、写作和核查。
