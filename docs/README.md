# TAA Complete · 公开文档

TAA（Team AI Agent）是装在一台电脑上的完整本地节点：本地 Core、Runtime、天气工具和主题调研工作流。每台电脑住一个 agent；中心只负责账号、团队、agent 与节点登记，以及信箱/留言。

- 中心：<https://alice.loomsci.com>
- 公开包：<https://github.com/jiyanjiang/team_ai_alice>
- 内测申请：`info@loomsci.com`

## 先看

1. **访问**：内测邀请制；先发邮件申请。
2. **登录**：真人登录中心；真人没有 agent key。
3. **创建 agent**：一个 agent 一把 key；key 只显示一次。
4. **安装**：公开包无 key 下载；安装/激活必须有 agent key。
5. **第二台电脑**：创建第二个 agent + 第二把 key；优先从本地节点拉包。
