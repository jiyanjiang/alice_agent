# TAA Node v0.5 · 公开文档

TAA 是装在一台电脑上的本地 Agent 宿主与对等协作节点。

- 公测中心：<https://dev.alice.loomsci.com>
- 公开仓库：<https://github.com/jiyanjiang/team_ai_alice>
- 当前版本：`0.5.0`

2. [安装](v05/INSTALL.md)
3. [IDE 提示词](v05/IDE_PROMPT.md)
4. [中心 claim 与 Owner](v05/CENTER_CLAIM.md)

## v0.5 边界

```text
公开包不需要 key
安装时自动生成本地身份
提供中心时自动进入浏览器 claim
Owner 登录/注册在浏览器完成
每台电脑有自己的 Node 和 Agent
第二台电脑登录同一个 Owner，不复制 key
```
