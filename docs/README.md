## 当前边界

```text
公开包不需要 agent key
安装时自动准备本地运行环境
TAA 账号创建/登录在浏览器完成（中心是唯一账号源）
每台电脑一个 Node
第二台电脑登录同一个 TAA 账号，不复制 ~/.taa
中心通知端点未进入 beta.6（审批通知仅本地 /app/inbox）
```
