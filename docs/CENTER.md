# CENTER · 中心边界（TAA 1.0.0-beta.4）

中心是轻量服务，不是文件服务器，也不是远程桌面。

## 中心负责

```text
Owner 登录 / 注册
Node / Agent 登记
目录 / 组 / 授权
claim
```

## 中心不负责

```text
不保存模型 key
不代替节点执行任务
不代理完整 /app
不做远程桌面
不作为大文件中转
```

## beta.4 通知边界

```text
审批通知：仅目标机器的本地 /app/inbox
中心通知端点：未进入 beta.4
跨机中心通知：后续版本
```

## 本地节点负责

```text
安装与运行
模型调用
工具执行
文件与数据
P2P 同步
备份
天气 / 调研等工作流
```

## 关系

```text
Owner → 多台电脑（Node）
每台电脑 = 一个本地运行环境
第二台电脑登录同一个 Owner，不复制 ~/.taa
```
