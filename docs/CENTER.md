# CENTER · 中心边界

中心是轻量服务，不是文件服务器，也不是远程桌面。

## 中心负责

```text
真人登录
邀请
Team / Agent / Node 登记
信箱 / 留言
工具市场入口（可选）
```

## 中心不负责

```text
不中转大文件
不保存模型 key
不代替节点执行任务
不做远程桌面
不做 agent key 转移
```

## 本地节点负责

```text
安装与运行
模型调用
工具执行
文件与数据
天气 / 调研等工作流
```

## 关系

```text
Human → Team → Agent → Node
```

第二台电脑是第二个 agent + 第二把 key；本地节点可以供包，但中心仍然是身份与登记的权威。
