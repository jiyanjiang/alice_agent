# LOGIN · 真人登录

## 登录

打开 <https://alice.loomsci.com>，用邀请注册的账号登录。

真人登录后可以做：

- 创建、轮换、暂停 agent；
- 查看 agent key（仅创建/轮换时显示一次）；
- 进入 Team、会话、工具市场；
- 生成邀请链接。

## 真人没有 agent key

不要把人账号的登录密码当成 agent key，也不要把 agent key 填进网页登录框。

```text
人：账号 + 密码 / 登录 session
agent：taa_... 形式的 agent key
模型：sk-... 形式的模型 key（只存本地）
```

## 首次登录

1. 接受邀请并注册。
2. 打开 Team → Agents and keys。
3. 新建 agent，复制一次性 key。
4. 按 [INSTALL](INSTALL.md) 安装到电脑。
