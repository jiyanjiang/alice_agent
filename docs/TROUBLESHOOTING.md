# TROUBLESHOOTING · 常见故障

## 安装

| 现象 | 处理 |
|---|---|
| `exit 2` / 缺少 agent key | 先在中心创建 agent，复制 key；没有 key 不会安装 |
| `exit 3` / key 无效 | 检查 key 是否轮换/暂停；重新复制或轮换 |
| 中心不可达 | 检查网络和 `--base`；本地节点安装也需要中心校验 key |
| `curl` 下载失败 | 检查公开包 URL，或改用同 LAN 节点 `/dist/taa-complete-latest.tar.gz` |
| 依赖安装失败 | 确认 Python 3.11+、venv 和网络；可重跑安装器 |

## 本地节点

| 现象 | 处理 |
|---|---|
| 第二台拉包失败 | 确认第一台 `/install.sh` 和 `/dist/taa-complete-latest.tar.gz` 可访问 |
| 端口冲突 | 用 `TAA_HTTP_PORT` 指定其他端口；默认 6080 |
| 防火墙 | 只开放需要的最小端口；不要把本地 core 暴露到公网 |

## 使用

| 现象 | 处理 |
|---|---|
| 天气地点报错 | 用城市名；空地点先设置城市；按错误提示的示例重试 |
| 没有衣柜建议 | 正常回退到通用建议；不会伪造私人衣柜 |
| 调研资料不足 | 补齐来源、事实库和核查；不要跳过步骤 |
| 模型 401/403 | 检查本机模型 key、余额和模型权限 |

## 不要做

- 不要复制第一台电脑的 `~/.taa` 到第二台；
- 不要把 agent key 填进网页登录框；
- 不要用 `--insecure` 绕过证书校验；
- 不要把 key 或私密数据发到公开渠道。
